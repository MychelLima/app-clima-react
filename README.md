# App do Clima

Aplicação web para consultar o clima atual e a previsão dos próximos 7 dias de qualquer cidade, construída como projeto de estudo na trilha JavaScript → TypeScript → React.

## Funcionalidades

- Busca de clima por nome da cidade
- Exibição de temperatura, descrição e condição atual
- Previsão dos próximos 7 dias
- Tratamento de erros (cidade não encontrada, falha de conexão)
- Indicador de carregamento durante as buscas

## Tecnologias

- React
- TypeScript
- Vite
- API [Open-Meteo](https://open-meteo.com/) (geocoding e previsão do tempo)

## Como rodar localmente

\`\`\`bash
git clone https://github.com/SEU-USUARIO/app-clima-react.git
cd app-clima-react
npm install
npm run dev
\`\`\`
